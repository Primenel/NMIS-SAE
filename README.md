# NMIS 2021 SAE Technical Demonstration

- Temporary demonstration.
- Covers 2021 only.
- Includes all currently governed SAE indicators.
- Provides a browser-based presentation using Shinylive/webR.
- Contains no restricted NMIS microdata.
- Excludes the direct-survey benchmark panel.
- Provides no data-download functionality.
- Is not the permanent official public dissemination platform.
